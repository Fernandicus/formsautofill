# When to use this skill

Use this skill when reviewing a SKILL or when creating a new SKILL.

# When NOT to use this skill

Do not use this skill when the task is unrelated to SKILL review or when the task is unrelated to SKILL creation.

# Official Documentation

https://antigravity.google/docs/skills

# Instructions

- Make sure the SKILL description is clear and concise and provides the necessary information to the agent to understand when to use the SKILL.
- Checking for redundancy in the SKILL that is being reviewed or created (e.g., if content is duplicated or already included in another SKILL).
- Identifying areas for improvement in the SKILL that is being reviewed or created, such as:
    - Enhancing grammar.
    - Adding samples.
    - Creating references folder with extra information.
- Make relations between SKILLS by adding the path to the SKILL related SKILL (e.g., For practical configuration samples (e.g., Strict TSConfig, Turborepo linking), refer to `./skill-name/SKILL.md`).
