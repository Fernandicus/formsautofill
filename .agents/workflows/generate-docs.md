description: Create or Modify Documentation
---

Before starting read any SKILL related to write documentation.

1. Ask about what the user wants to document. Give some options and remember the selected option as `<chosen-option>`:
- a) Full feature
- b) Peace of code
- c) Code Logic or Process
- d) Other (define)

2. Enter into the `/docs` folder and look if that documentation already exists. If so look for the last updated doc, read it and use it to have more context.

3. Go to the main folder (the one that contains all the code: ./src, ./app, ./api, etc) and look for the files and/or peaces of code that contains the `<chosen-option>` and try to understand exactly what it does or how it works. 

4. Go to the `/docs` folder again and write the documentation in markdown format. If there was already documentation about the topic, create a new version of the doc, do not ovewrite the older version (for example, autocomplete-system.md -> autcomplete-system-v2.md -> autcomplete-system-v3.md, etc)
